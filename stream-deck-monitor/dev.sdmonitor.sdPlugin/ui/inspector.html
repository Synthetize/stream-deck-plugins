Status

Helper… RTSS (FPS)… CPU temp… GPU temp…

GPU usage, GPU temperature, RAM, disk and network need nothing. CPU temperature needs a kernel driver, so it runs a small helper with administrator rights (one UAC prompt, scheduled task) and the free PawnIO driver. FPS comes from RivaTuner (RTSS), which must be running.
